# PDFMate 1.0 구현 계획

- Windows 앱의 첫 탭은 파일 병합이다. PDF 탭은 파일별로 열며 두 문서를 같은 창에서 나란히 볼 수 있다.
- 입력 파일을 백그라운드에서 PDF로 준비해 실제 페이지 수를 표시한다. Office 변환은 데스크톱 Excel과 PowerPoint를 사용한다.
- 드래그 순서와 출력 위치를 독립적으로 유지한다. 최초 추가 파일이 `보고서.pdf`라면 같은 폴더에 `보고서_병합.pdf`를 저장한다.
- PDF 페이지 삭제 후에는 문서 폴더에 `원본명_편집됨.pdf`를 저장한다. 이름 충돌 시 번호를 붙이고 기존 파일을 보존한다.
- 페이지 렌더링, 변환, 병합, 인쇄를 UI 밖에서 실행한다. 인쇄 게이지는 Windows 인쇄 큐로 보내는 페이지 수를 표시한다.
- 샘플 문서로 형식별 페이지 수, 혼합 병합, 저장 위치, 중복 파일명, 편집 결과, 인쇄 경로를 확인한다. Windows용 실행 ZIP과 GitHub 릴리스 빌드를 준비한다.
