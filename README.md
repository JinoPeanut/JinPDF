# JinPDF 1.2.11

Windows에서 PDF를 여러 탭으로 보고, 파일을 합치고, 페이지를 삭제하고, 인쇄할 수 있습니다.

[최신 Windows 실행 ZIP 다운로드](https://github.com/JinoPeanut/JinPDF/releases/latest)

## 실행

1. `JinPDF-v1.2.11-win-x64.zip` 전체를 쓰기 가능한 폴더에 풉니다.
2. `JinPDF.exe`를 실행합니다. Windows 10/11 x64 및 .NET Framework 4.8 환경을 대상으로 합니다. PDF 처리용 Python은 실행 압축 파일에 포함되어 있습니다.
3. 엑셀·파워포인트를 변환하려면 해당 Microsoft Office 데스크톱 앱이 설치되어 있어야 합니다.

## 사용 방법

- **파일 병합** 탭에 PDF, JPG, JFIF, PNG, XLS/XLSX, PPT/PPTX 파일을 끌어다 놓거나 `파일 추가`로 선택합니다. 각 행 왼쪽의 손잡이를 드래그하거나 `Alt+↑`·`Alt+↓`로 순서를 바꿀 수 있습니다. 오른쪽 아래의 `병합하기`를 누르면 현재 목록의 위에서 아래 순서로 처리합니다. 파일별 페이지 수는 작업 중 `상태`에 표시됩니다. 처음 추가한 파일의 폴더에 `첫파일명_병합.pdf`를 만들고, 저장에 성공하면 목록을 비우고 결과를 새 탭으로 엽니다. 실패하면 `병합하기`로 다시 시도할 수 있습니다.
- **파일 제외**는 파일 행의 `×`를 누르거나, 체크박스로 파일을 골라 `선택 항목 제외`를 누르면 됩니다. 이 동작은 병합 목록에만 적용됩니다. 처음 추가한 파일을 제외하면, 목록에 남은 파일 중 가장 먼저 추가했던 파일의 폴더에 병합 결과를 저장합니다.
- **최근 병합**은 앱을 실행한 동안 마지막으로 성공한 병합 한 건의 결과 파일명, 파일 수, 총 쪽수를 보여줍니다. `파일별 쪽수 보기`를 누르면 입력 파일과 쪽수를 PDF에 들어간 순서대로 확인할 수 있습니다.
- **파일 한 개**를 추가한 상태에서도 `병합하기`로 `_병합.pdf`를 만들고 새 탭에서 열 수 있습니다.
- **PDF 열기**로 문서를 여러 탭에서 엽니다. 문서 탭과 나란히 보기 탭은 각각 오른쪽의 `×`로 닫을 수 있습니다. `나란히 보기`는 열린 PDF 두 개를 한 창에서 비교합니다. 페이지 이동, 맞춤 보기, 확대를 사용할 수 있습니다.
- **방향키**로 PDF 문서 탭에서 페이지를 넘길 수 있습니다. `←`·`↑`는 이전 페이지, `→`·`↓`는 다음 페이지입니다.
- **확대·축소**는 PDF 페이지 위에서 `Ctrl`을 누른 채 휠을 움직이거나 `+`·`−` 키를 누르면 됩니다. 최대 400%까지 확대할 수 있습니다. 확대 메뉴 옆의 **선명하게**를 켜면 200% 이상에서 페이지를 더 높은 해상도로 그리고 글자와 선의 윤곽을 보정합니다. 이 설정은 화면 보기에 적용됩니다.
- **선택 페이지 삭제**는 왼쪽 썸네일에서 체크한 페이지를 뺀 새 PDF를 `원본명_편집됨.pdf`로 저장합니다. 왼쪽 목록에서 첫 쪽부터 마지막 쪽까지 이어서 스크롤할 수 있습니다. 스크롤해도 체크 상태가 유지됩니다. 결과는 새 탭에서 열립니다. 파일명이 겹치면 `(2)`, `(3)` 순으로 번호가 붙습니다.
- **보기 회전**은 PDF 상단의 왼쪽·오른쪽 회전 버튼 또는 Ctrl+Shift+←/→로 현재 페이지를 90°씩 돌립니다. 보기 방향은 해당 탭의 페이지별로 유지됩니다. 저장 파일과 인쇄에는 원래 방향이 적용됩니다.
- **전체선택·선택 해제**는 병합 파일 목록과 PDF 왼쪽 페이지 목록 위에서 사용할 수 있습니다. 선택된 개수를 함께 표시하며, 화면 밖 페이지까지 선택합니다.
- **인쇄**를 누르면 Windows 인쇄 대화상자에서 프린터와 페이지 범위를 고를 수 있습니다. **인쇄 여백**을 체크하면 사방의 여백을 1~50 mm 사이에서 직접 설정할 수 있습니다. 기본 입력값은 15 mm입니다. 체크를 풀면 Windows 인쇄 설정의 기본 여백을 사용합니다. 용지 크기는 인쇄 창의 프린터 설정에서 선택합니다. PDF 자체의 흰 여백, 용지 비율, 프린터의 인쇄 가능 범위에 따라 실제 여백은 더 넓을 수 있습니다. 앱 하단의 게이지는 Windows 인쇄 큐로 보내는 페이지 수를 표시합니다.

## 탐색기에서 파일 병합하기

1. JinPDF 상단에서 **탐색기 메뉴 → JinPDF로 병합 등록**을 선택합니다.
2. 탐색기에서 파일을 고른 뒤 **우클릭 → 보내기 → JinPDF로 병합**을 선택합니다. Windows 11에서 보내기가 보이지 않으면 **더 많은 옵션 표시**를 엽니다.
3. JinPDF의 파일 병합 탭에서 순서를 확인한 뒤 **병합하기**를 누릅니다.

상단 탐색기 메뉴 버튼에서 등록 상태를 확인할 수 있습니다. 메뉴는 현재 Windows 사용자에게 등록됩니다. 실행 파일 위치를 옮기면 새 위치에서 다시 등록하세요. 메뉴를 지우려면 JinPDF에서 **탐색기 메뉴 → JinPDF로 병합 등록 해제**를 선택합니다.

## 샘플로 확인하기

`samples`의 다섯 파일을 함께 병합하면 Excel 1쪽, PowerPoint 2쪽, JPG 1쪽, PNG 1쪽, PDF 3쪽을 합친 **8쪽**이 됩니다. 결과에서 두 페이지를 선택해 삭제하면 `_편집됨.pdf`는 **6쪽**입니다.

400% 확대에서 선명하게 옵션을 비교할 수 있습니다. [50dpi 스캔 테스트 PDF](output/pdf/JinPDF-low-resolution-scan.pdf)

## 빌드 및 GitHub Releases

Windows x64에서 Python 3.12를 사용합니다.

```powershell
python -m pip install -r requirements.txt
$env:PYTHONPATH = (Resolve-Path src).Path
python -m unittest discover -s tests -v
./build.ps1
```

`dist`에 실행 ZIP과 샘플 ZIP이 생성됩니다. 프로젝트 폴더를 GitHub 저장소 최상위에 올린 뒤 `v1.2.11` 태그를 푸시하면 Windows 빌드가 두 ZIP을 해당 태그의 Releases에 첨부합니다. 같은 워크플로를 Actions에서 수동 실행해 ZIP을 받을 수도 있습니다.
