# JinPDF 1.2.1

Windows에서 PDF를 여러 탭으로 보고, 파일을 합치고, 페이지를 삭제하고, 인쇄할 수 있습니다.

[최신 Windows 실행 ZIP 다운로드](https://github.com/JinoPeanut/JinPDF/releases/latest)

## 실행

1. `JinPDF-v1.2.1-win-x64.zip` 전체를 쓰기 가능한 폴더에 풉니다.
2. `JinPDF.exe`를 실행합니다. Windows 10/11 x64 및 .NET Framework 4.8 환경을 대상으로 합니다. PDF 처리용 Python은 실행 압축 파일에 포함되어 있습니다.
3. 엑셀·파워포인트를 변환하려면 해당 Microsoft Office 데스크톱 앱이 설치되어 있어야 합니다.

## 사용 방법

- **파일 병합** 탭에 PDF, JPG, JFIF, PNG, XLS/XLSX, PPT/PPTX 파일을 끌어다 놓거나 `파일 추가`로 선택합니다. 각 행 왼쪽의 손잡이를 드래그하거나 `Alt+↑`·`Alt+↓`로 순서를 바꿀 수 있습니다. 오른쪽 아래의 `병합하기`를 누르면 현재 목록의 위에서 아래 순서로 처리합니다. 파일별 페이지 수는 작업 중 `상태`에 표시됩니다. 처음 추가한 파일의 폴더에 `첫파일명_병합.pdf`를 만들고, 저장에 성공하면 목록을 비우고 결과를 새 탭으로 엽니다. 실패하면 `병합하기`로 다시 시도할 수 있습니다.
- **파일 제외**는 파일 행의 `×`를 누르거나, 체크박스로 파일을 골라 `선택 항목 제외`를 누르면 됩니다. 이 동작은 병합 목록에만 적용됩니다. 처음 추가한 파일을 제외하면, 목록에 남은 파일 중 가장 먼저 추가했던 파일의 폴더에 병합 결과를 저장합니다.
- **최근 병합**은 앱을 실행한 동안 마지막으로 성공한 병합 한 건의 결과 파일명, 파일 수, 총 쪽수를 보여줍니다. `파일별 쪽수 보기`를 누르면 입력 파일과 쪽수를 PDF에 들어간 순서대로 확인할 수 있습니다.
- **파일 한 개**를 추가한 상태에서도 `병합하기`로 `_병합.pdf`를 만들고 새 탭에서 열 수 있습니다.
- **PDF 열기**로 문서를 여러 탭에서 엽니다. 문서 탭과 나란히 보기 탭은 각각 오른쪽의 `×`로 닫을 수 있습니다. `나란히 보기`는 열린 PDF 두 개를 한 창에서 비교합니다. 페이지 이동, 맞춤 보기, 확대를 사용할 수 있습니다.
- **선택 페이지 삭제**는 왼쪽 썸네일에서 체크한 페이지를 뺀 새 PDF를 `원본명_편집됨.pdf`로 저장합니다. 왼쪽 목록에서 첫 쪽부터 마지막 쪽까지 이어서 스크롤할 수 있습니다. 스크롤해도 체크 상태가 유지됩니다. 결과는 새 탭에서 열립니다. 파일명이 겹치면 `(2)`, `(3)` 순으로 번호가 붙습니다.
- **인쇄**를 누르면 Windows 인쇄 대화상자에서 프린터와 페이지 범위를 고를 수 있습니다. 앱 하단의 게이지는 Windows 인쇄 큐로 보내는 페이지 수를 표시합니다.

## 샘플로 확인하기

`samples`의 다섯 파일을 함께 병합하면 Excel 1쪽, PowerPoint 2쪽, JPG 1쪽, PNG 1쪽, PDF 3쪽을 합친 **8쪽**이 됩니다. 결과에서 두 페이지를 선택해 삭제하면 `_편집됨.pdf`는 **6쪽**입니다.

## 빌드 및 GitHub Releases

Windows x64에서 Python 3.12를 사용합니다.

```powershell
python -m pip install -r requirements.txt
$env:PYTHONPATH = (Resolve-Path src).Path
python -m unittest discover -s tests -v
./build.ps1
```

`dist`에 실행 ZIP과 샘플 ZIP이 생성됩니다. 프로젝트 폴더를 GitHub 저장소 최상위에 올린 뒤 `v1.2.1` 태그를 푸시하면 Windows 빌드가 두 ZIP을 해당 태그의 Releases에 첨부합니다. 같은 워크플로를 Actions에서 수동 실행해 ZIP을 받을 수도 있습니다.
